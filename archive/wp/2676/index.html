Tips：备份三步走，资料全无忧

Yibie · 2010年9月29日 · 原载 GTDStudy

才九月中旬，笔者就经历了一次惨痛的损失，在一次开机之后就发现硬盘上所有的个人文档、电子书、电影、音乐统统都不见了，整个硬盘就好像是全新的一样，干 干净净。一点渣滓都没有给笔者剩下。不过，幸好笔者一直知道狡兔有三窟的道理，绝大多数的资料还是通过不同的途径寻找来了。不过，这件事也提醒了笔者，资 料很重要，平时一定要做好保管的工作，否则一旦不见自已哭都来不及。

第一步：把系统文件定时搬到安全的地方

操作系统是最容易出现问题的地方，同时也是最花精力去维护的地方。如果把系统备份好，就不必每次系统出现问题就重装，软件以及很多设置又要重新弄过了。

应用 Windows 系统还原来备份系统文件

不知道为什么有的人就是一定要用别的工具来代替 Windows 原本就有的功能。其实，如果没有太多的要求单纯追求资料可以定时备份，系统还原就够简单好用。因为系统还原很简单，备份之前没有太多的设置要做，而且每次 备份静悄悄地在后台进行，所以只要启用了备份功能，以后就根本不用花费心思来管它。而还原也很简单，你可以任意选择一个还原点来恢复你的文件，把系统返回 到没有问题的状态中去。

启用 Windows 的备份功能也很简单，只要遵循以下步骤就可以了（由于笔使用的 Win7，所以以下描述也以 Win7 内部的设定为准，不过 Windows 系统变化不是很大，很容易就可以猜出来）：

  1. 进入 控制面板
  2. 点击 系统与安全
  3. 打开 备份与还原
  4. 之后跟着系统的提示做/选择就可以了

创建系统映像

系统映像是一个特殊的文件，这个文件以 保持原样 的方式，把系统文件都以一种特殊的方式压缩成一个文件，当要恢复系统的时候，只要把该文件解压到相应的分区上就可以了。而且，恢复之后一切保持当初备份的原样，不必再重新设置，很方便。

GHOST 一直很流行，因为用它创建的系统映像可以很方便的备份系统，把系统的文件都放到一个文件里面，要恢复的时候只要用 GHOST 就可以把文件全部恢复了。但其实在 Win7 里面就集成了这个创建系统映像的功能（我不清楚 XP 里面是否自带，XP 的朋友可以自已找找看）。这项功能，同样是在控制面板的系统与安全下，很容易就可以找到。

当你打开 创建系统映象 之后，系统首先会帮你找备份系统映像的地方，然后你就可以自已选一个地方备份你的系统映像，可以是你硬盘上的一个分区、也可以是你的 U 盘/移动硬盘、也可以把系统映像刻在光盘上。在这里，我推荐大家把系统映像刻在光盘上，这样可以最大限度的保证系统映像这个文件本身不会损坏。不过，你也 可以在多个地方创建系统映像，比如刻录系统映像光盘，也在移动硬盘上创建系统映像。

第二步：妥善保管个人资料

这次笔者损失最多的地方，莫过于个人文档部分了，也幸好笔者一直有把资料保存在移动硬盘上的习惯，也因此损失没有这么严重。另外，由于有很多个人写的文档都保存在网上，所以也容易就可以找回来，算是不幸中的大幸。

按年份整理个人的资料，刻录光碟

记得在一次实习的时候，我的指导老师向我展示了他整理的文档，所有的文档都按照先按照年份归类，然后在下面分为工作、生活、娱乐这文件夹，里面又按照月份 将自已工作/生活/娱乐方面资料归档。十分整齐，没有一个文件是没有归属的。他每年还会定时把这些个人的H资料刻成光碟，并在光碟的表面标注年份。记忆中 他说过，每年的资料整理过后，刚好就是 600MB 左右，刚好就是一只刻录碟的容量。

所以，一旦他的数据发生什么意外，他就一定有办法可以恢复。其实，就一个好习惯这么简单。如果一个人，连自已硬盘上的文件都不整理的话，他就连自已硬盘哪些文件需要保存都不知道，就不要谈如何去备份个人的资料了。

把文档同步到网络空间

这次数据损失不大，是因为我有使用网络硬盘的习惯。当我把网络硬盘的客端下载下来之后，一同步就可以把以前的文件找回来了。只不过一些电影、音乐因为体积太大没有同步到网络硬盘上，没法恢复。

Dropbox ：国外的优秀网络空间

  • 简介 （资料来自同步控)：

    安装完Dropbox后，在“我的文档”中将会显示一个名为“My Dropbox”的文件夹。
任何你放入该文件夹的东西都会被自动同步到你的Dropbox账户。
你可以同步文件、分享文件（将文件夹权限设置为公共）、恢复文件——Dropbox会保存30天的文件更改记录。
您的所有文件也将可以通过在线网站访问，这样即便在没有安装Dropbox的电脑上也能使用。

数据银行

  • 简介：

    数据银行是国内新兴的网盘服务提供商，它面向所有注册用户，提供多种文件类型的存储、传递、共享服务；
“安全”、“快捷”、“稳定”、“易用”是其的服务宗旨。

  • 更加详细的应用评测，请参考以下文章：

云存储服务“数据银行”PC客户端评测（组图）

  • 我的使用体验

数据银行安装方便，同步的速度也较快，而且提供了文件外链服务，可以一个性的分享多份文件给他人，十分方便。而且数据银行是中国企业巨头“华为”推出的，所以可以安心地把文件放在上面。但是在第一次同步资料的时候，一定要记住 等数据同步完成之后再关机 ，否则之后的同步将无法完成。

  • 邀请链接

如果通过我的 邀请链接 来注册，会为我的数据银行增加50分积分，多谢。

快盘
  • 简介

可以参考：金山快盘初体验

  • 我的使用体验

快盘，使用起来十分贴心，如果关机的时候有文件没有同步完成，它就会在你关机的时候，弹出一个选项框给你选择是否“立即关机”。而且，文件是否同步 完成可以通过文件的图标上直接反映，这点和 Dropbox 一样。而且，快盘提供的文件版本管理功能，你可以通过快盘的“文件时光机”的功能找到该文件的上一个版本，很方便。

但是，文件的传输速度就不如数据银行快。

  • 邀请链接

通过我的 邀请链接 注册可以给我的快盘增加 1G 的空间，谢谢！

第三步：文件夹同步工具帮你自动搬文件

第二步中介绍了很多网络空间服务，不过这些服务的特点是要在硬盘上新建一个文件夹，用以放下你要同步的文件。有时候，我们的个人资料都以自已习惯的方式放 到别处，如果每次备份都要自已把文件搬到同步用的文件夹，这很费时费力，所以就需要用到一个文件夹同步工具，来帮你把要备份的文件自动同步过去。

当然，你也可以直接把你个人的资料都放到同步用的文件夹中去，只不过如果全部都放进去的话，恐怕网络空间不够大。

SyncToy

  • 简介

微软出品的小工具。功能简单，使用方便。

  • 我的使用体验

安装了 SyncToy 之后，你可以马上设定同步的任务，并选择三种同步方式：

①Synchronize：双向同步。同时把两个文件夹里面的文件都更新到最新。

②Echo：单向同步。只把负责把一个文件夹里面的内容更新到另外的一个文件夹。

③Contribute：更安全的单向同步方式。会保留所有文件。
